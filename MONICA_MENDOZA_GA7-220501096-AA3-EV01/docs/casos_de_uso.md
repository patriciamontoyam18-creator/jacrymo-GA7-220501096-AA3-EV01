# Casos de uso del módulo

**Actor principal:** Administrador de JACRYMO.

### CU-01 Registrar producto
1. El administrador abre el módulo.
2. Diligencia los datos del producto.
3. Selecciona registrar.
4. El sistema valida la información.
5. El sistema guarda el producto y actualiza la tabla.

### CU-02 Consultar productos
1. El administrador ingresa al inventario.
2. El sistema muestra los productos.
3. El administrador puede escribir un término de búsqueda.
4. El sistema filtra los resultados.

### CU-03 Actualizar producto
1. El administrador selecciona Editar.
2. El sistema carga la información.
3. El administrador modifica los datos.
4. Selecciona Guardar cambios.
5. El sistema actualiza el registro.

### CU-04 Eliminar producto
1. El administrador selecciona Eliminar.
2. El sistema solicita confirmación.
3. Si confirma, el sistema elimina el registro.
4. La tabla se actualiza.
