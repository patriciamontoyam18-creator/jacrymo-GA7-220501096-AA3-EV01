# Historia de usuario

## HU-01 - Gestionar productos

**Como:** administrador o encargado del inventario de JACRYMO.

**Quiero:** registrar, consultar, actualizar y eliminar productos.

**Para:** mantener organizada y actualizada la información del catálogo y las existencias.

### Criterios de aceptación

- El sistema permite ingresar referencia, nombre, categoría, talla, precio y stock.
- El sistema valida los campos obligatorios.
- El sistema permite consultar los productos registrados.
- El sistema permite buscar por referencia, nombre o categoría.
- El sistema permite editar un producto existente.
- El sistema solicita confirmación antes de eliminar.
- El sistema muestra mensajes de operación exitosa.
- El sistema calcula el valor estimado del inventario.
